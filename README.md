# Echo
Hecho para ayudar, no para reemplazar.

Sitio oficial estático. Para publicar: descomprime el paquete, sube el contenido de Echo-sitio (no la carpeta contenedora) a la raíz del repositorio Echo-prog15/Echo. En Settings → Pages selecciona Deploy from a branch, main, / (root), Save. El sitio esperado es https://echo-prog15.github.io/Echo/.

La descarga contiene la versión 0.15.0 probada, sin cambios de código. La instalación y las actualizaciones son manuales. Revisa la política de privacidad antes de publicar. La vista del inicio es ilustrativa, no una captura real.
