Política de privacidad.

Aplicable a Echo 0.15.2 · 25 de noviembre de 2026

Qué guarda Echo

La extensión utiliza el almacenamiento local de Chrome para guardar el nombre opcional, el progreso educativo, las preferencias de recordatorios y, si activas el registro, los accesos y el tiempo aproximado por plataforma y fecha. También conserva información técnica local para calcular sesiones y seleccionar consejos sin repetir consecutivamente el mismo mensaje.

Qué no recopila

Echo no registra el contenido de tus conversaciones, prompts, contraseñas ni respuestas de las plataformas de IA. No requiere una cuenta propia ni envía las estadísticas a un servidor de Echo.

Permisos

El permiso de almacenamiento conserva tus datos; las alarmas permiten actualizar las estadísticas; el permiso de inactividad ayuda a estimar el tiempo activo. El acceso a los dominios compatibles permite detectar la plataforma y mostrar consejos. Si los consejos están activados, se muestra uno al abrir o recargar una página compatible, sin intervalo de espera entre mensajes.

Tu control

El registro de actividad está desactivado inicialmente. Puedes activarlo o desactivarlo y borrar las estadísticas desde Echo. Desactivar el registro no borra los datos anteriores. Puedes desactivar los consejos por separado y personalizar su duración. Desinstalar la extensión elimina su almacenamiento local, pero no las copias exportadas.

Copias de seguridad

Las copias JSON incluyen progreso, nombre, estadísticas y preferencias. No están cifradas. Guárdalas de forma segura y elimina las que ya no necesites.

Sitio web y terceros

Esta página no incorpora analítica propia, cookies publicitarias ni formularios de recopilación. GitHub aloja el sitio y puede tratar datos técnicos de conexión según su política de privacidad. Las plataformas de IA tienen sus propias políticas, independientes de Echo.

Contacto y cambios

Para consultas sobre el proyecto, utiliza el repositorio oficial de Echo. No publiques información personal ni copias de seguridad en espacios públicos. Esta política deberá actualizarse si cambian las funcionalidades o el tratamiento de datos.
